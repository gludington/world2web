Open Game Settings → Configure Settings → World2Web. First-time users should click Setup Wizard at the top of the panel. It takes about ten minutes and walks you through three steps.

Step 1: Create your site

  • Repo name: the name for your site's GitHub repository, such as my-campaign-site. Pick something you'll recognize, and remember it.

  • Deploy to: click Cloudflare, Netlify or Vercel. A new browser tab opens that provider's own setup flow, which copies the World2Web site template into your GitHub account and hosts it.

Important: when the provider asks for a repository or project name, type the same name you entered in Foundry. Netlify and Cloudflare suggest world2web-site-template, so change it. Vercel fills in your name automatically:

When the provider finishes, it builds your site and shows a placeholder page that says "Your site is ready". Write down the site's address (for example my-campaign-site.netlify.app). That is the link you'll share with your players. Then return to Foundry for step 2.

Step 2: Create a GitHub token

Foundry needs a Personal Access Token (a kind of password) to add posts to your repository. The token only gives World2Web permission to change this one repository. It doesn't control who can read your site, which is always public.

Click Open GitHub & Continue. GitHub's token page opens with most options already filled in:

  1. Token name: already set to "World2Web". Change it if you like.

  2. Expiration: choose No expiration. If you pick a date instead, publishing will stop working on that date until you create a new token and enter it in Foundry.

  3. Repository access: choose Only select repositories and pick the repository you created in step 1. This is the one setting the wizard can't fill in for you.

  4. Permissions: Contents: Read and write is already selected. Leave it.

Click Generate token and copy it right away. GitHub only shows it once.

Step 3: Save your details

Back in Foundry, enter:

  • GitHub Repo Owner: your GitHub username.

  • GitHub Repo Name: the repository name from step 1 (already filled in).

  • GitHub Personal Access Token: the token you just copied.

Click Save. World2Web checks that it can reach your repository before saving. If something is wrong, it tells you what (a misspelled name, or a token without access to the repository) so you can fix it right there. See @UUID[.iG9Rmy0Kci8odneA]{Troubleshooting} for details.

To change the repository or token later without creating a new site, use the GitHub Connection button in Configure Settings → World2Web.
