Nothing is published until you choose to publish it. Any journal can be set up for the web; then you publish its pages one at a time.

Open the journal and click the gear icon in its header:

This opens Publishing Settings for the journal:

  • Publish this journal to the web: check this to allow the journal's pages to be published. Unchecking it later removes all of the journal's posts from the site the next time you publish.

  • Author: who posts appear to be written by. By default this is the character of the first player who owns the journal, or "Game Master" if no player owns it. To set it yourself, drag an Actor onto Author Actor override to use that Actor's name and portrait (and their biography, on supported game systems), or type a name and image instead.

  • Root path: where the journal appears on your site. By default this follows the journal's folders in Foundry, so a journal in the folder Arc 1 → Session Notes appears under /arc-1/session-notes/. Type a different path to move it, for example Campaign/Arc 1.

  • Tags: optional, comma-separated. Each tag gets its own page on the site listing every post with that tag.

  • Post order: how this journal's own page on the site lists its posts. Choose Manual to match the page order in Foundry.

  • Homepage (Game Master only): feature this journal on your site's front page, in its own post order. Show above Recent Posts suits a "Start Here" journal; Replace Recent Posts suits a guide meant to be read in order, like this one. Only one journal per world can be featured. If several worlds publish to the same site, each world's own page gets its own featured journal.
